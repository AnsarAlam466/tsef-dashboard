# The Solution

## Ten&See — a verified student-housing marketplace, run by an AI-native operating system

Ten&See connects students to verified housing near Malaysian universities. But the platform is only the interface — the real product is the intelligence layer underneath it.

### For students

- **Verified listings** with real photos, real prices, real availability — filterable by university, building, budget, and room type
- **One conversation** — inquire on the platform or WhatsApp and get matched to actual available units, instead of chasing five agents
- **Fair pricing** — market-rate transparency (e.g., master room at D'Latour ≈ RM1,500/person) so students stop overpaying

### For agents & landlords

- **Qualified demand on tap** — students arrive pre-filtered by budget, building, and move-in date
- **List once, sell everywhere** — a unit logged once is matched against every compatible student lead
- **Faster closings** — Ten&See handles the matching; the agent handles the keys

### How we operate differently

Ten&See is an **AI-native company**. Every student, room, agent, conversation, and decision is a node in a living graph:

| Human does | System does |
|---|---|
| Gets a WhatsApp inquiry | Reads intent, pre-fills the lead, suggests a match |
| Logs a unit from an agent | Checks duplicates, matches against open student leads |
| Closes a deal | Computes the fee, updates revenue, learns pricing signals |
| Has a meeting | Extracts decisions, assigns owners and deadlines |

The team stays small. The system scales.
